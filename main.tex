\begin{abstract}

The goal of this experiment is to measure X-ray diffraction patterns of various solid samples in order to describe their crystal structure at the atomic/molecular level. Any crystalline solid consists of a regular 3-dimensional packing of cells, the shape of which corresponds to one of fourteen Bravais lattices. These 3D patterns create multiple planar layers of various orientations within the crystal, each capable of producing a peak in the observed diffraction pattern. From that peak, Bragg's law $n\lambda = 2d \sin \theta$ (where $n =1$ for a first-order plane) can be used to deduce the inter-planar distance $d$ of each diffraction plane of the crystal. Using this, if the Miller indices of the different planes are known, one can identify the Bravais lattice and calculate the lattice parameter(s) of the crystal.
